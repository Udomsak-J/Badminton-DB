# 🏸 Badminton Billing Bot

บอท LINE + หน้าเว็บแดชบอร์ด (LIFF) สำหรับกลุ่มตีแบด: ผู้จัดก๊วนเปิดรอบล่วงหน้าได้หลายวัน ระบุ วัน/เวลา/สถานที่/ค่าใช้จ่าย, สมาชิกกดปุ่ม **เข้าร่วม** ในแชทได้เลย, ผู้จัดก๊วนดูสถานะใครเข้าร่วมแล้วบ้างแบบเรียลไทม์ผ่านหน้าเว็บ และระบบ **สรุป+ส่งบิลเข้ากลุ่มอัตโนมัติ** หลังหมดเวลารอบ
สร้างด้วย Firebase (Firestore) + Netlify Functions + LINE Messaging API + LIFF — ใช้ได้ฟรีทั้งหมดในระดับการใช้งานกลุ่มเล็ก

---

## สถาปัตยกรรมโดยสรุป

```
ผู้จัดก๊วนแตะลิงก์ --> หน้าเว็บแดชบอร์ด (create-session.html, LIFF)
                          --> create-session-web.js (เปิดรอบ)
                          --> sessions-list-web.js (ดูสถานะเรียลไทม์ โพลทุก 5 วิ)
                          --> close-session-web.js (ปิดรอบก่อนเวลา)
                                    |
                                 Firestore
                                    ^
กลุ่ม LINE  <--webhook-->  line-webhook.js (ข้อความ + ปุ่มเข้าร่วม/ออกจากรอบ)
                                    ^
billing-check.js (ทุก 10 นาที) ------┘  ตรวจรอบหมดเวลา -> คำนวณบิล -> push เข้ากลุ่ม
```

- **create-session.html (LIFF)**: หน้าแดชบอร์ดเดียว มีทั้งฟอร์มเปิดรอบใหม่ และรายการรอบที่เปิดอยู่/ประวัติ อัปเดตอัตโนมัติทุก 5 วินาที
- **line-webhook**: เมื่อเปิดรอบ (จากเว็บหรือข้อความ) บอทจะส่งข้อความพร้อม**ปุ่ม "เข้าร่วม"/"ออกจากรอบ"** เข้ากลุ่ม สมาชิกกดปุ่มได้เลยไม่ต้องพิมพ์ — รองรับหลายรอบเปิดพร้อมกัน เพราะปุ่มผูกกับรอบนั้นๆ โดยตรง
- **billing-check**: รันอัตโนมัติทุก 10 นาที ตรวจรอบที่ถึงเวลาสิ้นสุดแล้วยังไม่ปิดบิล แล้วส่งสรุปเข้ากลุ่มให้เอง

## ข้อมูลที่ผู้จัดก๊วนกรอกตอนเปิดรอบ (ผ่านหน้าเว็บ)

1. สถานที่
2. วันที่เล่น
3. เวลาเริ่ม / เวลาจบ
4. ค่าสนาม (บังคับ)
5. ค่าลูกแบต (ไม่บังคับ)
6. ค่าใช้จ่ายอื่นๆ (ไม่บังคับ)

สูตรคำนวณ: `(ค่าสนาม + ค่าลูกแบต + ค่าอื่นๆ) / จำนวนคนที่เข้าร่วม = ค่าใช้จ่ายต่อคน`

เปิดรอบล่วงหน้ากี่วันก็ได้ และเปิดได้หลายรอบพร้อมกัน (เช่น เปิดรอบวันจันทร์กับวันพุธพร้อมกัน) — ระบบจะปิดและคิดบิลแต่ละรอบอัตโนมัติตามเวลาสิ้นสุดของรอบนั้นๆ

## คำสั่งที่ใช้ในกลุ่ม (แบบข้อความ ใช้เสริมจากหน้าเว็บได้)

| คำสั่ง | ความหมาย |
|---|---|
| `สร้างรอบ` | บอทส่งลิงก์หน้าแดชบอร์ด (LIFF) **← แนะนำให้ใช้ทางนี้เป็นหลัก** |
| กดปุ่ม "เข้าร่วม" / "ออกจากรอบ" ใต้ข้อความเปิดรอบ | วิธีหลักในการเข้าร่วม ใช้ได้แม้มีหลายรอบเปิดพร้อมกัน |
| `เปิดรอบ สนามA 20/09/2026 19:00-21:00 ค่าสนาม 600 ค่าลูกแบต 100` | เปิดรอบด้วยข้อความล้วน (ไม่ผ่านเว็บ) |
| `เข้าร่วม` / `ออกจากรอบ` (พิมพ์) | ใช้ได้เฉพาะตอนมีรอบเปิดอยู่รอบเดียว ถ้ามีหลายรอบให้กดปุ่มแทน |
| `เพิ่มค่าใช้จ่าย 100 ลูกแบด` | เพิ่มค่าใช้จ่ายเข้ารอบล่าสุดที่เปิดอยู่ |
| `สรุปรอบ` | ปิดรอบล่าสุดและคิดบิลทันที (หรือกดปุ่ม "ปิดรอบตอนนี้" ในหน้าเว็บก็ได้ เจาะจงรอบได้ชัดกว่า) |
| `ยกเลิกรอบ` | ยกเลิกรอบล่าสุดโดยไม่คิดเงิน |
| `ช่วยเหลือ` | แสดงคำสั่งทั้งหมด |

## ขั้นตอนติดตั้ง

ดูขั้นตอนสร้าง LINE OA / Firebase / Netlify / LIFF แบบละเอียดได้จากที่ตั้งค่าไว้ก่อนหน้านี้ (ไม่เปลี่ยนแปลง) สรุปคร่าวๆ:

1. สร้าง Messaging API channel ที่ LINE Developers Console, ปิด Auto-reply / เปิด Allow bot to join group chats
2. สร้าง Firebase project (Spark ฟรี) เปิด Firestore, ดาวน์โหลด Service Account Key
3. Deploy repo นี้ขึ้น Netlify (ตั้ง Base directory ให้ตรงกับตำแหน่งไฟล์จริงใน repo ถ้าไม่ได้อยู่ที่ root)
4. ใส่ Environment variables: `LINE_CHANNEL_SECRET`, `LINE_CHANNEL_ACCESS_TOKEN`, `FIREBASE_PROJECT_ID`, `FIREBASE_CLIENT_EMAIL`, `FIREBASE_PRIVATE_KEY`
5. สร้าง LIFF app ใน LINE Developers Console ชี้ Endpoint URL ไปที่ `https://<เว็บของคุณ>/create-session.html` แล้วใส่ `LIFF_ID`, `LINE_LOGIN_CHANNEL_ID` เพิ่มใน env vars
6. ตั้ง Webhook URL ใน LINE Console เป็น `https://<เว็บของคุณ>/.netlify/functions/line-webhook`
7. เชิญบอทเข้ากลุ่ม (ต้องสร้างกลุ่มโดยเปิด **"สมาชิกเข้าร่วมกลุ่มโดยอัตโนมัติ"** ตั้งแต่ตอนสร้างกลุ่ม ไม่งั้นบอทจะเข้ากลุ่มไม่ได้)

### Firestore index ที่ต้องสร้าง (ระบบจะโชว์ลิงก์สร้างให้เองตอนใช้งานจริงครั้งแรก)

ใช้งานไปเรื่อยๆ แล้วเจอ error `FAILED_PRECONDITION: The query requires an index` ที่ไหน ให้กดลิงก์ในข้อความ error นั้น (ดูได้จาก Netlify → Logs → Functions) จะพาไปสร้าง index ที่ Firebase Console ให้อัตโนมัติ ปกติต้องสร้างประมาณนี้:
- `sessions`: groupId (Asc), status (Asc), createdAt (Desc) — ใช้ตอนเช็ครอบล่าสุด
- `sessions`: groupId (Asc), status (Asc), startTime (Asc) — ใช้ตอนแสดงรายการรอบที่เปิดอยู่ในแดชบอร์ด
- `sessions`: groupId (Asc), createdAt (Desc) — ใช้ตอนแสดงประวัติในแดชบอร์ด
- `sessions`: status (Asc), endTime (Asc) — ใช้ตอน billing-check ปิดบิลอัตโนมัติ

## โครงสร้างไฟล์

```
badminton-bot/
├── netlify.toml
├── package.json
├── .env.example
├── public/
│   ├── index.html                   # หน้า landing เฉยๆ
│   └── create-session.html          # แดชบอร์ด LIFF: ดูสถานะเรียลไทม์ + ฟอร์มเปิดรอบ
└── netlify/functions/
    ├── line-webhook.js              # รับคำสั่ง/ปุ่มจากกลุ่ม LINE (message + postback)
    ├── billing-check.js             # scheduled function ปิดรอบ+ส่งบิลอัตโนมัติ
    ├── liff-config.js               # ส่ง LIFF_ID ให้หน้าเว็บ
    ├── create-session-web.js        # รับฟอร์มจากเว็บ สร้างรอบ + ส่งปุ่มเข้ากลุ่ม
    ├── sessions-list-web.js         # ส่งรายการรอบ (เปิดอยู่/ประวัติ) ให้แดชบอร์ด
    ├── close-session-web.js         # ปิดรอบ+คิดบิลทันทีจากแดชบอร์ด
    └── lib/
        ├── firebaseAdmin.js
        ├── lineClient.js            # เรียก LINE API + verify signature
        ├── lineLogin.js             # ตรวจ id_token จาก LIFF
        └── sessionService.js        # โลจิกหลัก: parse คำสั่ง, คำนวณบิล, Firestore queries
```

## ⚠️ เรื่องฟรี 100%

- Netlify Free tier / Firebase Spark plan: เพียงพอสำหรับกลุ่มตีแบดทั่วไป
- LINE push message ฟรี 200 ข้อความ/เดือน — การเปิดรอบแต่ละครั้งใช้ 1 push (ข้อความปุ่ม) + การปิดบิลอัตโนมัติอีก 1 push ต่อรอบ นับรวมแล้วสำหรับกลุ่มที่เล่น 2-3 รอบ/สัปดาห์ยังห่างไกลโควตามาก
